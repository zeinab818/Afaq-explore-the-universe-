## ✨ Overview

**Āfāq** is an interactive space exploration platform designed for curious minds who want to discover the universe, understand astronomical phenomena, and follow humanity's journey through space.

From planets, moons, stars, and galaxies to space missions, cosmic discoveries, and real-time space information, Āfāq brings different areas of astronomy together in one immersive experience.

The platform also features a dedicated section exploring the relationship between selected Quranic verses and astronomical topics, with an emphasis on respectful interpretation and scientific references.

## 🚀 Features

### 🌍 Explore the Solar System

- Discover the Sun, planets, dwarf planets, moons, asteroids, and comets.
- Explore detailed celestial-body information.
- Browse astronomical images and related discoveries.

### 🔭 Deep Space Exploration

- Explore galaxies and nebulae.
- Discover black holes, stars, and other fascinating cosmic objects.
- Learn about constellations and the night sky.

### 🛰️ Space Missions

- Explore space missions and their scientific objectives.
- Discover mission details and related imagery.
- Learn about humanity's exploration of space.

### 🌌 Live Space & Astronomy

- Follow International Space Station information.
- Explore tracked space objects.
- Access astronomy-related data and space information through dedicated API endpoints.

### ☄️ Astronomical Events

- Explore meteor showers and celestial events.
- Discover upcoming astronomical phenomena.
- Learn about comets and other observable objects.

### 🔬 Research & Discoveries

- Explore astronomy-related research and scientific discoveries.
- Read educational articles about major cosmic phenomena.
- Dive deeper into the science behind the universe.

### 📖 Space & Quran

- Explore selected Quranic verses related to astronomical topics.
- Read contextual explanations and scientific discussions.
- Access references and further reading.
- Distinguish between Quranic interpretation, scientific research, and established scientific observations.

### 🔖 My Exploration

- Save interesting discoveries and exploration items.
- Manage saved items using browser Local Storage.
- Access saved content without requiring an account.

## 🧪 APIs & Data Sources

Āfāq uses API integrations and external astronomical resources to retrieve and present space-related information.

Examples of data sources and services used in the project include:

- **NASA Image and Video Library** — astronomical and space imagery.
- **NASA APIs** — astronomy-related data and imagery where configured.
- **API Ninjas** — planetary information.
- **Astronomical data services** — solar information, sunrise and sunset times, and other space-related data.

> Data availability depends on the corresponding external services and API configurations.

## ⚙️ Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm

### 1. Clone the repository
```
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate to the project directory
```
cd space
```

### 3. Install dependencies
```
npm install
```

### 4. Configure environment variables

Create a `.env.local` file in the project root and add the API keys required by the application.
```
# Add the environment variables required by your API integrations.
# Never commit real API keys or secrets.
```

Refer to the project's environment configuration before running the application.

### 5. Run the development server
```
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🏗️ Production Build

To create an optimized production build:
```
npm run build
```

To run the production version locally:
```
npm run start
```

## 🔐 Environment Variables & Security

- Keep API keys and private credentials in environment variables.
- Never commit `.env` or `.env.local`.
- Configure the required environment variables in your deployment platform.
- Use `.env.example` to document variable names without exposing secret values.

## 🎨 Design Philosophy

Āfāq is designed around an immersive, elegant cosmic experience.

Its visual direction combines:

- A deep-space inspired dark interface.
- Subtle cosmic colors and atmospheric details.
- Clear information hierarchy.
- Responsive layouts for different screen sizes.
- Interactive elements that encourage exploration and discovery.

The goal is to make scientific information feel approachable without sacrificing clarity or accuracy.
